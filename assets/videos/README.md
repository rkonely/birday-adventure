# 🎬 Папка для видеофайлов (Assets / Videos)

Сюда вы можете поместить свои видеоролики. Код автоматически подхватит их при загрузке страницы.

### Имена файлов:
1. `intro_idle.mp4` — **Видео 1 (Ожидание):**
   * Зацикленное видео интерьера грузового самолета / кабины, пока игрок находится на титульном экране и еще не нажал кнопку «Начать приключение».
   
2. `intro_form.mp4` — **Видео 2 (Реакция на клик / Форма):**
   * Видео, где инструктор реагирует на игрока (оборачивается, достает калькулятор/планшет, кивает), поверх которого открывается форма ввода имени и даты.
   
3. `intro_transition.mp4` — **Видео 3 (Переход в первый этап):**
   * Видео, где инструктор подтверждает допуск (нажимает кнопку калькулятора, отдает честь), люк самолета распахивается и птица вылетает навстречу облакам к Этапу I.

---

### Рекомендации по формату:
* **Формат:** MP4 (кодек H.264 / AAC) для максимальной совместимости во всех браузерах (Chrome, Firefox, Safari, Edge, мобильные).
* **Разрешение:** 1280x720 (720p) или 1920x1080 (1080p), соотношение 16:9.
* **Примечание:** Если какого-то видео еще нет, игра не ломается — на экране автоматически отображается анимированный ретро-холст с пиксельной птицей-инструктором и пролетающими облаками!
